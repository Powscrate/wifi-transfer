# **App Name**: Wifi Transfer Hub

## Core Features:

- QR Code Generation: Generate a QR code on the PC that, when scanned by a mobile device, directs it to the web app URL.
- File Transfer (PC to Mobile): Enable file transfer from the PC to the connected mobile device via a drag-and-drop interface on the web app.
- File Transfer (Mobile to PC): Enable file transfer from the mobile device to the connected PC via the web app interface.
- Mobile-Optimized Interface: Provide a fully functional, mobile-optimized user interface when accessed via the mobile device's browser.
- Wifi Direct Communication: Establish communication between the web app on the PC and the mobile device using Wifi-Direct Protocol.
- Local IP auto-detection: Automatically detect the server's local IP address for connection purposes.

## Style Guidelines:

- Primary color: A deep sky blue (#3498db) to evoke connectivity and trustworthiness.
- Background color: Light gray (#ecf0f1), very slightly tinted blue, for a clean, modern backdrop.
- Accent color: A warm orange (#e67e22) for interactive elements and highlights, contrasting with the blue tones.
- Body and headline font: 'Inter', a grotesque sans-serif with a modern look.
- Simple, clear icons representing file types and actions, using the accent color for interactive states.
- Glassmorphism effects: semi-transparent panels with blurred backgrounds to give a modern and airy feel
- Subtle transitions and animations to provide feedback during file transfers and connections.
